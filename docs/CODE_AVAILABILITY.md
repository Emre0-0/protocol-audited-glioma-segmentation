# Code availability statement

The code for the subject-disjoint partition audit, model training, official
BraTS lesion-wise evaluation, and subject-cluster statistical analysis is
available at https://github.com/Emre0-0/protocol-audited-glioma-segmentation
(version v1.0.0). The repository includes fixed partition identifiers,
training configurations, aggregate results, dependency specifications, and
reproduction instructions. MRI volumes, segmentation masks, and trained model
weights are not distributed in this repository. Access to the source imaging
datasets is governed by the respective data providers' terms.

This is a code-availability statement, not a promise of public model weights,
unrestricted dataset redistribution, or clinical deployment readiness.
